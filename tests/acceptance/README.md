# Compound Knowledge 验收证据

本目录保存只读原版基线、固定场景、真实运行证据与评分材料。每个正式运行位于 `runs/<scenario>/<run-id>/`；三种场景各有一份原版基线和四份新版平台运行，共 15 份隔离运行。

模板和 Python 静态检查只验证证据结构与防护规则，**不得以静态合同、合成 fixture 或文档声明替代真实平台运行**。只有在隔离工作区完成安装、全新会话、六阶段流程和独立回读探针，并保存原始截图或文本记录的真实平台运行，才能满足发布门槛。

运行开始前复制模板并填写实际证据路径；不要将本目录、评分材料或其他 QA 输入加入业务上下文。
