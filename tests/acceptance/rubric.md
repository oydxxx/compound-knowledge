# 三轮对比评分量表

每个判断都必须指向具体运行产物、行为证据或差异说明。评分者在盲评时不看平台标签，并记录证据路径与理由。

| 维度 | 原版基线 | 新版平台运行 | 证据要求 |
| --- | --- | --- | --- |
| 语义保真 | 适用 | 适用 | 行为 ID、关键决策与阶段产物 |
| 内容完整 | 适用 | 适用 | 六阶段产物和角色/任务结果 |
| 逻辑结构 | 适用 | 适用 | 输入、计划、审查与最终沉淀链 |
| 可执行性 | 适用 | 适用 | 工作日志、阻塞/恢复和可写边界 |
| 事实准确 | 适用 | 适用 | 固定材料、来源与数据截止时间 |
| 中文自然度 | **N/A** | 适用 | 仅评新版中文可读性 |
| 跨平台一致性 | **N/A** | 适用 | 仅比较同场景四份新版 |

`zs-confidence` 的非数字化自检不是 QA 数字评分：不得把它的措辞、百分比或任何数字化信心表述作为量表分数。原版的中文自然度和跨平台一致性必须标为 `N/A`，不能补填分数。

本量表、模板和静态检查只约束证据结构，**不得以静态结果替代真实平台运行**；真实平台运行、全新会话记录与原始证据才是发布门槛。
