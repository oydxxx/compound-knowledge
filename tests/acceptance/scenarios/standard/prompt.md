# Standard 固定任务输入

## 任务

根据固定用户访谈、历史知识和业务目标，制定「团队协作模板」功能的中文发布内容计划。目标受众为现有小团队客户；计划覆盖产品内、帮助中心、邮件和客户成功触达，但不得实际发送或发布。

## 必须满足

- 只读取本场景 `context/` 的固定材料；不得联网或用可能变化的资料补充事实。
- 完成六工作流，且 `plan` 必须检索历史知识；`review` 必须有战略一致性与数据准确性两项独立职责结果。
- 内容计划需包含受众、核心承诺、信息架构、渠道映射、两周节奏、负责人角色、指标、风险、事实来源与待验证项。
- `zs-work` 必须使用 [decision-script.md](decision-script.md) 中两项有依赖的动态任务；第二项第一次失败后只补跑失败任务。
- 不得发送邮件、更新生产帮助中心、发布内容或写入计划外路径。
