# Compound Knowledge 插件说明

这是 Compound Knowledge 的可分发插件包（版本 `3.1.0`）。六个 `skills/zs-*/SKILL.md` 是唯一权威工作流正文；平台目录只处理发现、安装和兼容入口，不能复制或改写核心流程。

## 工作流与调用

| 规范名 | 中文名称 | 作用 |
| --- | --- | --- |
| `zs-boom` | 梳理想法 | 整理原始想法、问题和约束。 |
| `zs-plan` | 制定计划 | 把方向组织为可执行计划。 |
| `zs-confidence` | 校准把握 | 识别已知、未知与验证方式。 |
| `zs-review` | 审查计划 | 做战略对齐和数据准确性检查。 |
| `zs-work` | 执行工作 | 实施计划并记录执行信息。 |
| `zs-compound` | 沉淀知识 | 把经验保存到 `docs/knowledge/`。 |

兼容命令可使用 `/zs:boom` 等旧入口；若平台不支持中文命令别名，请保留英文规范名并直接用中文自然语言描述意图：

```text
请帮我复盘这次活动，找出可沉淀为团队知识的结论，并保存到本地知识目录。
```

## 四个平台的安装、更新与卸载

| 平台 | 安装 | 更新 | 卸载 |
| --- | --- | --- | --- |
| Claude Code | 安装包含六个标准技能的插件；如需裸旧入口，再将适配包的 `zs:*.md` 安装到消费方 `.claude/commands/`。详见[Claude Code 适配](adapters/claude-code/README.md)。 | 替换实际启用的兼容文件，清理缓存并在全新会话确认没有重复入口。 | 移除实际启用的插件和/或兼容命令，清理缓存后验证不可发现。 |
| Codex | 将每个 `skills/zs-*` 目录放入消费方 `.agents/skills/`。详见[Codex 适配](adapters/codex/README.md)。 | 替换同名目录，刷新缓存，在全新会话验证六项发现结果。 | 删除对应 `.agents/skills/zs-*` 目录，刷新缓存后验证不可发现。 |
| 腾讯 WorkBuddy | 逐个导入由标准技能目录生成的确定性归档。详见[WorkBuddy 适配](adapters/workbuddy/README.md)。 | 校验 `manifest.sha256` 后以同一规范名替换；重复条目须先卸载。 | 逐个移除六个导入项，清理缓存并在全新会话验证。 |
| TRAE SOLO | 将每个 `skills/zs-*` 目录放入消费方 `.agents/skills/`。详见[TRAE SOLO 适配](adapters/trae-solo/README.md)。 | 替换同名目录，按实际版本刷新缓存并在全新会话确认。 | 删除对应目录、刷新缓存并在全新会话确认不可发现。 |

安装、更新和卸载都以**全新会话中的实际结果**为准。适配文档是操作清单，不是平台已实测的声明；请把截图或文本证据保存到验收记录。可查看[平台适配总览](adapters/README.md)了解消费方规则、能力回退和授权约束。

## 数据、联网与外部操作

- 本插件不收集遥测，不要求联网，并且本地优先；运行时不新增网络依赖。
- 宿主平台可按自身产品设置联网、调用模型或处理数据；这不等同于本技能主动联网。
- 外部检索是可选宿主能力，不是运行依赖；使用时应记录检索日期和来源。
- 项目规则、参数和自然语言不能授予自动外部操作权限。发布、发送、登录、删除及其他外部副作用始终需要人工授权。

更多边界见[隐私说明](PRIVACY.md)、[安全说明](SECURITY.md)和[维护规范](AGENTS.md)。
