# 本地化与稳定协议合同

本合同供维护者与 QA 使用。所有面向用户的说明、提问、选项、输出模板、角色提示、安装文档和安全说明使用**自然简体中文**；翻译必须保留冻结基线中的目标、判断标准、流程、权限、默认行为与产物语义。

## 不得翻译或改写的协议

| 类别 | 锁定内容 |
| --- | --- |
| YAML 字段 | `type`、`tags`、`confidence`、`created`、`source` |
| 知识枚举 | `insight`、`playbook`、`correction`、`pattern` |
| 审查优先级 | `P1`、`P2`、`P3` |
| 技能与角色标识 | `zs-*`、角色文件名、任务 ID 与行为 ID |
| 路径 | `plans/`、`docs/knowledge/`、`docs/solutions/` 与计划声明的交付路径 |
| 参数与占位符 | `$ARGUMENTS`、YAML 键、代码、URL 与文件名 |
| 许可证 | `MIT License` 正文、版权及许可声明 |

不得翻译这些 token 的拼写、大小写、分隔符或路径层级；中文文档应在相邻位置解释其含义，而不是创建中文协议副本。

## 名称与显示规则

- 规范技能名为英文连字符形式（例如 `zs-boom`）；中文显示名和自然语言示例用于发现与引导。
- Claude 兼容入口 `/zs:*` 只能出现在兼容 wrapper、迁移说明或实测记录中，不得继续作为核心唯一入口。
- 英文可保留在产品专名、协议标识、代码、路径、命令和许可证中；其他可见 prose 应为中文。

## 语义核对

每次改写一个工作流时，对照冻结的行为 ID 检查：输入与提问、上下文读取、角色职责、写入路径、阻塞、默认值和续接均未增删。中文表达可重写，行为结果不得漂移。
