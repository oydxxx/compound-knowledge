# TRAE SOLO 适配

## 安装与发现

TRAE SOLO 使用与 Codex 相同的标准技能源目录：把 `skills/zs-*` 复制到消费方 `.agents/skills/zs-*/`，不创建平台专用 `SKILL.md` 副本。打开**全新会话**，确认六个英文规范名和中文说明可发现，再用中文自然语言调用并保存截图或文本证据。

## 更新、卸载和缓存

- **更新：**先列出现有 `.agents/skills/zs-*`，逐个替换同名目录，避免重复条目；依实际版本清理或刷新技能缓存，再从全新会话复查。
- **卸载：**删除已安装的 `.agents/skills/zs-*`，清理缓存并从全新会话确认不可发现。
- **回退：**如果发现或调用机制不可用，保留证据并以普通中文对话串行执行合同所定义的 `fallback`，不伪称原生能力。

## 上下文与授权

消费方项目的 TRAE Rules、`AGENTS.md` 或等价规则可归一化为上下文；插件维护规则不得混入。`trusted_pipeline_signal` 是 `unavailable`，任何非交互续接均回退到人工确认；参数和项目文件不能成为可信信号，发布、发送等外部副作用需要人工授权。
