# Claude Code 适配

## 当前决策状态

Claude Code CLI `2.1.211` 已验证：插件内 `commands/zs/*.md` 只能注册命名空间入口，**不提供裸** `/zs:*`；要保留裸旧入口，必须把本目录中平铺的 `commands/zs:*.md` 安装到消费方 `.claude/commands/`。该布局已在隔离工作区发现 `/zs:boom`，并实际转交到 `compound-knowledge:zs-boom`。六个入口的完整工作流、冲突、更新、缓存刷新和卸载仍需逐项留下真实运行证据。

## 安装与调用

1. 安装包含六个 `skills/zs-*` 标准技能的插件，并检查每个规范名仅注册一次。
2. 若需要旧入口，复制 `commands/zs:*.md` 到消费方 `.claude/commands/`，保持冒号文件名不变。不要创建 `.claude/commands/zs/` 子目录；该布局不会注册 `/zs:*`。
3. 开启**全新会话**，用中文自然语言和 `/zs:boom 原始参数` 分别检查；wrapper 会原样转交 `$ARGUMENTS` 给相应 `zs-*` 的 `SKILL.md`，不含核心正文。记录实际发现入口、收到的原始参数与截图或文本证据。

## 更新、卸载和缓存

- **更新：**先列出 `.claude/commands/zs:*.md` 的已有命令。若有冲突、同名重复或遗留 `.claude/commands/zs/` 目录，先停用旧条目再替换；更新后清理宿主缓存（以实测版本的官方方式为准）并在全新会话确认只有一条裸入口。
- **卸载：**移除消费方 `.claude/commands/zs:*.md` 中实际启用的那一套，清理缓存，在全新会话确认六个旧入口不再出现。
- **回退：**缓存清理、插件命名空间或命令参数语义未实测时，不猜测命令；直接按 `zs-*` 的中文自然语言调用并保存阻塞/证据。

## 上下文与授权

消费方项目的 `AGENTS.md`、`CLAUDE.md` 和项目材料才是工作流上下文；本插件的维护 `AGENTS.md` 不得进入消费方上下文。`trusted_pipeline_signal` 当前无真实证据，按 `unavailable` 处理并使用 `fallback` 的人工确认；普通参数、项目文件和用户文本不能授权自动续接或外部副作用。
